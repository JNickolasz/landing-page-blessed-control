# Documentação Técnica — Blessed Control Landing Page

Bem-vindo à documentação oficial da Landing Page do **Blessed Control | Blessed Academy Jiu-Jitsu**. Este diretório centraliza a arquitetura do projeto, o pipeline de deploy no GitHub Pages, o histórico detalhado das melhorias de performance e UX aplicadas, e o roadmap da próxima etapa (Capítulo 2).

---

## Sumário da Documentação

1. **[Arquitetura, Comandos & Deploy (`01-arquitetura-e-comandos.md`)](./01-arquitetura-e-comandos.md)**
   Visão geral da stack (Express + EJS + Tailwind CSS CLI), estrutura de diretórios (incluindo `media/apk/app-blessed-control-v1.apk`), fluxo de dados em `src/data.js`, scripts de compilação estática (`index.html`) e CI/CD via GitHub Actions (`.github/workflows/deploy.yml`).
2. **[Melhorias Implementadas (`02-melhorias-implementadas.md`)](./02-melhorias-implementadas.md)**
   Registro detalhado de todas as otimizações aplicadas nos **Capítulos 1 e 3** (Performance, Build de Produção, Otimização de Imagens `.webp`, Download Direto do APK, UX do Lightbox e Acessibilidade).
3. **[Roadmap: Capítulo 2 — SEO, Open Graph & PWA (`03-roadmap-capitulo-2-seo-pwa.md`)](./03-roadmap-capitulo-2-seo-pwa.md)**
   Especificação técnica completa para a futura implementação de Meta Tags Open Graph (WhatsApp/Instagram), Twitter Cards, `manifest.json` e suporte nativo a PWA no iOS Safari.
